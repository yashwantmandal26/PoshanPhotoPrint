# Poshan Photo Print (पोषण फोटो प्रिंट) 📸📄

Android application designed for Anganwadi workers, Poshan Abhiyaan staff, and community supervisors. Automatically extracts GPS Map Camera timestamps, sorts photos in ascending order, and generates compact, print-ready A4 reports.

## Key Highlights

- **📅 Automatic GPS & EXIF Date Extraction**: Reads GPS banner stamps with zero network connection.
- **⚡ Super Smooth & Jitter-Free UI**: Built with Jetpack Compose, featuring spring-physics pinch-to-zoom, fluid drag-and-drop reordering, and tactile haptic feedback.
- **📐 Flexible A4 Layout Presets**: Grid, Compact, Left, Center, and Right formatting options.
- **✂️ Full-Screen Photo Viewer & Precise Cropping**: Double-tap zoom, in-place date modification, and Smart Auto-Cropping.
- **🚀 One-Tap Sharing & Printing**:
  - **WhatsApp Mode**: High-compression (<400 KB) PDF output.
  - **HQ Print Mode**: 300 DPI high-definition PDF spooling.
- **🔒 100% Offline & Private**: All image processing, OCR, layout rendering, and storage occur entirely on-device.
